## ✨ Características del Proyecto

Este portfolio fue construido con el objetivo de ser rápido, seguro y libre de dependencias pesadas, demostrando que con las bases sólidas de la web se pueden lograr interfaces premium de alto rendimiento.

- **Vanilla Stack**: HTML5, CSS3 y JavaScript puro. Sin frameworks, sin tiempos de compilación.
- **Bilingüe (ES/EN)**: Sistema de cambio de idioma nativo e instantáneo implementado con manipulación de DOM y clases CSS.
- **Glassmorphism UI**: Diseño moderno oscuro con transparencias y acentos rojos, manteniendo coherencia con un perfil técnico/backend.
- **Formulario de Contacto**: Interfaz preparada para ser conectada vía EmailJS.
- **Responsive Design**: Totalmente adaptable a dispositivos móviles.

## 🛠️ Tecnologías

- **HTML5**: Semántica web y estructura.
- **CSS3**: Grid, Flexbox, variables CSS, keyframes (animaciones), variables y selectores avanzados.
- **JavaScript**: Lógica de internacionalización (i18n), scroll dinámico y manipulación del DOM.
